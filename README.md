# NOIR & FORM — Premium Grooming Studio Concept

A premium men's grooming studio website and appointment-booking experience concept.

NOIR & FORM explores a digital experience built around personal style, craftsmanship, service discovery, barber profiles, and a guided appointment journey. Its visual direction is dark, editorial, cinematic, and intentionally restrained.

<sub>**Project status:** Concept / prototype. This repository is presented as portfolio work, not as a verified live barbershop or operational booking service.</sub>

## Project at a glance

- **Industry concept:** Premium men's grooming and barber studio
- **Website focus:** Brand presentation, barber and service discovery, and booking journey
- **Visual direction:** Dark editorial design, strong typography, cinematic imagery, and refined motion
- **Experience intent:** Responsive desktop and mobile layouts
- **Demo content:** Fictional studio, staff, services, testimonials, prices, and contact details

## Intended website experience

The original project brief describes an experience intended to include:

- Studio introduction and brand storytelling
- Barber profiles and work presentation
- Service discovery with barber-aware selection
- Editorial gallery and image viewer
- Before-and-after presentation
- Testimonials and studio information
- A multi-step appointment flow with validation and confirmation states
- Mobile booking access and responsive navigation
- Accessibility, reduced-motion, performance, and SEO considerations

This is the intended scope described in the project brief. It does not independently verify that every listed interaction is implemented or that any booking is connected to a real calendar or business.

## Design direction

The concept aims for a premium grooming identity rather than a conventional local barbershop template. Its visual language uses deep charcoal surfaces, warm off-white typography, restrained bronze accents, generous spacing, asymmetrical compositions, and carefully controlled motion.

## Technical foundation

The repository contains a React and TypeScript-oriented frontend toolchain, including Vite and TanStack Start-related dependencies. This describes the repository's technical foundation only; no production backend or live booking integration is claimed.

## Demo-content boundaries

- Barber names, profiles, images, services, prices, testimonials, address, and contact details are fictional demo content.
- No real barbershop or operating business is represented.
- Booking is a front-end concept only; no real appointment, calendar, SMS, payment, or customer-management integration is claimed.
- Feature completion and deployment status should be checked against the current repository before making more specific implementation claims.
