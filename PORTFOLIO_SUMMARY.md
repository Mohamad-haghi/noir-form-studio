# NOIR & FORM — Portfolio Overview

**Project type:** Premium grooming studio website and booking-experience concept  
**Positioning:** Service-business website design  
**Status:** Concept/prototype project; real booking operations are not claimed

## Overview

NOIR & FORM is a premium men's grooming studio website concept. Its design brief focuses on editorial art direction, a strong mobile experience, service and barber presentation, and a guided appointment-booking journey.

## Intended experience

The project brief defines:

- Premium brand introduction and studio presentation
- Barber profiles and service discovery
- Editorial work/gallery presentation
- Barber- and service-aware booking journey
- Appointment form with validation and confirmation states
- Responsive navigation and mobile booking access
- Accessibility, reduced-motion, and SEO considerations

## Technical foundation

The repository includes a modern TypeScript and React-based frontend toolchain, with Vite and reusable UI dependencies.

## Scope and transparency

The repository README is an extensive implementation brief. This summary describes the intended product and design scope; it does not independently verify that every interaction is implemented or connected to a real booking backend. Names, staff profiles, testimonials, prices, address, and contact information in the concept are fictional demo data.
